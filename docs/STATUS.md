# GoreeCloud Maps — Status

**Stage:** Source development preview; not deployed or production accepted.

**Map-first visual correction (November 6, 2026):** [PR #19](https://github.com/GoreeCloud/maps/pull/19) replaces the panel-first dashboard composition with a full-window geographic canvas, a floating search bar and controls, a compact desktop sidebar and an expandable phone bottom sheet. Before map consent, an original **illustrative** locally bundled SVG depicts streets, river, park and a sample route, clearly labeled as not live geographic data. The real MapLibre engine and third-party tiles remain consent-gated; the illustration is removed when live map rendering starts and restored after revocation. [Browser run 42312829085](https://github.com/GoreeCloud/maps/actions/runs/42312829085) passed desktop 1440×900, tablet 820×1180, phone 390×844 and small phone 320×640 composition checks, plus existing keyboard, forced-colors and true Chromium zoom. Screenshot review caught and corrected an initially clipped phone navigation dock and overlapping preview status. The final screenshot set was visually inspected for those **specific defects**, not accepted as proof of comprehensive GC UI design, real device, screen reader or licensed production map service.

**Source present:** Web map client, Node proxy scaffold with optional Nominatim/OSRM adapters, bounded JSON POST request handling, local saved locations, local GeoJSON saved-place portability and local GPX 1.1 waypoint export, manual route coordinate entry, provider consent and automation tests.

**Verified automated checks (November 6, 2026):** Node tests, syntax checks, Vite build and production-dependency advisory check passed in GitHub Actions. A separate real Chromium test job passed synthetic desktop (1440×900), tablet (820×1180) and phone (390×844) journeys for map consent and canvas startup, coordinate search, local saves, GeoJSON import/export, manual routes, mocked search/routing providers, theme persistence, and rejection of obsolete route results. Evidence: [main browser CI 42244215895](https://github.com/GoreeCloud/maps/actions/runs/42244215895) and [PR #7 browser CI 42244883746](https://github.com/GoreeCloud/maps/actions/runs/42244883746). The runs preserved synthetic screenshots for review; no human visual acceptance is claimed.

**Accessibility and visual review progress (November 6, 2026):** [PR #9](https://github.com/GoreeCloud/maps/pull/9) merged fixes for phone consent-card clipping, tab-switch scroll retention and map-label/control overlap; it added a keyboard-activated map-center pin. The [post-merge main browser workflow](https://github.com/GoreeCloud/maps/actions/runs/42294074235) passed the prior synthetic three-viewport scenarios and additional desktop/phone keyboard and forced-colors checks. Screenshots from [PR #9 passing branch run](https://github.com/GoreeCloud/maps/actions/runs/42293848035) were inspected for the reported phone defects, and the consent action/link, Saved heading and map controls appeared accessible in those cases. See [scoped QA review](UI-QA-2026-11-06.md) for evidence and limitations.

**Consent-first renderer performance (November 6, 2026):** [PR #11](https://github.com/GoreeCloud/maps/pull/11) merged dynamic MapLibre/worker loading after the user selects **Load interactive map**, with a pending-load invalidation guard when consent is withdrawn. [Branch Chromium CI](https://github.com/GoreeCloud/maps/actions/runs/42295292604) verified the renderer code chunk was absent before consent and fetched afterward, while existing map interactions still passed. Vite reported an initial JS chunk of 17.96 kB versus approximately 1,086 kB before the split (uncompressed sizes); the deferred renderer chunk was about 1,105 kB. These are build sizes, not measured user download speeds.

**OSMF tile policy correction (November 6, 2026):** The default community tile service requires valid web Referer headers. The app's former `no-referrer` response was incompatible; source now uses `strict-origin-when-cross-origin`, disclosing only the website origin to cross-site HTTPS tile requests (alongside IP and tile coordinates). See the [official OSMF tile usage policy](https://operations.osmfoundation.org/policies/tiles/). Production provider compliance and live network behavior still need verification.

**Narrow CSS reflow check (November 6, 2026):** [PR #14](https://github.com/GoreeCloud/maps/pull/14) added synthetic Chromium tests at 640px and 320px CSS viewport widths (roughly equivalent to content width of a 1280px viewport viewed at 200%/400% zoom, **not** actual browser zoom). [Branch browser CI](https://github.com/GoreeCloud/maps/actions/runs/42298280672) passed horizontal overflow, native tab activation, route-input, import-control and attribution reachability checks. Screenshots were inspected for these narrow-width cases; full visual, native zoom and screen-reader acceptance remain pending.

**Actual Chromium zoom quality gate (November 6, 2026):** [PR #16](https://github.com/GoreeCloud/maps/pull/16) adds a first-party, Apache-2.0-attributed X11/XTest-based Chromium 200% and 400% zoom test that runs **only** under an isolated GitHub Actions Xvfb display. [Passing branch browser CI](https://github.com/GoreeCloud/maps/actions/runs/42303920433) measured baseline DPR 1.0 and native zoom DPR 2.0/4.0, with corresponding CSS viewport widths 640px/320px and document heights 976px/1027px. The previous fixed-height layout obscured most UI at 400%; a new short-viewport reflow rule enables normal page scrolling and removes overlay navigation. Tests confirm zero document horizontal overflow, keyboard tab activation, on-screen import-button hit testing and reachable map attribution without external provider calls. Extreme-zoom screenshot capture on virtual GPUs is visually unreliable; **no complete visual/manual/assistive-technology acceptance is implied**.

**Verified GC UI Foundations adoption (November 6, 2026):** The public [Foundations v1.0.1](https://github.com/GoreeCloud/gc-ui/releases/tag/foundations-v1.0.1) tarball was downloaded from the official release and matched SHA-256 `275d7e6dc9503b2e74b3190bcecf176d73d2345860e8a20fa5faa3b326cd2298`. The package declares Apache-2.0 licensing, no install scripts or runtime dependencies, and generated CSS tokens without network imports. Maps now pins its exact archive with npm integrity and uses its semantic color/typography tokens for light/dark Lagoon themes; [PR #17](https://github.com/GoreeCloud/maps/pull/17) merged at `a14216a7`; post-merge [source CI](https://github.com/GoreeCloud/maps/actions/runs/42306167754) and [browser CI](https://github.com/GoreeCloud/maps/actions/runs/42306167821) passed, including token-derived theme colors and 200%/400% zoom. Full GC UI component design acceptance remains unverified.

**Pending geolocation cancellation and consent-epoch validation (November 6, 2026):** [PR #18](https://github.com/GoreeCloud/maps/pull/18) introduces a guard for delayed browser geolocation results: revoking map consent invalidates pending callbacks, clears a device-derived route start, and invalidates stale route output; manually selected start points invalidate pending GPS. A synthetic Chromium test injects deferred callbacks without requesting physical GPS. Treat as proposed until branch CI and post-merge main CI confirm it. Browser permission prompts themselves cannot be programmatically recalled.

**Still unverified:** real hardware geolocation and touch behavior, screen-reader accessibility, complete keyboard-only/contrast and cross-browser/manual zoom audits, comprehensive GoreeCloud UI design-token and human visual acceptance, live geocoder/router and tile-service compatibility, provider licensing at production scale, operational HTTPS/reverse proxy, trusted deployments and production monitoring. CI uses mocked geocoder/router responses and intercepted tiles, not evidence of production navigation accuracy.

**Dependency reproducibility (November 6, 2026):** `package-lock.json` v3 is committed, with 90 package entries and SHA-512 integrity records for 89 registry packages. Both GitHub workflows now install application dependencies with `npm ci`; Playwright remains a pinned ephemeral CI-only browser-test dependency. Initial lock creation used an isolated authorized development checkout and the production-dependency audit reported no findings. Repeat and verify these checks in the feature-branch and merged-main CI before treating clean installs as accepted.

**Unavailable in this milestone:** native Android/iOS, turn-by-turn navigation, traffic and crowd reports, elevation/3D, offline tile downloading, account sync and live business data.
